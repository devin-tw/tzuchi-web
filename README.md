# Tzu Chi Canada Web

Tzu Chi Canada public web platform, served by Cloudflare Workers (static assets). Fast edge delivery and accessible system typography.

- **Design**: Brand palette (uniform navy, cloud white, granite, lotus green) and accessible system typography.
- **Languages**: English, Traditional Chinese, and French.
- **Volunteer Intake**: Responsive multi-step volunteer registration wizard at `/volunteer/signup`.

## Run and deploy

```sh
npm install
npm run dev       # local preview at http://localhost:8787
npm run deploy    # deploy to Cloudflare Workers
```

Only `public/` is uploaded.
